In the Proxmox web UI, click Create CT.
Select a Debian 12 or Ubuntu 22.04 template (download it under your storage's CT Templates tab first if it's not listed).
Set a hostname, e.g. lastfm-recs.
Set a root password.
Set the network to vmbr0 with DHCP (or a static IP).
Set resources: 1 vCPU, 1GB RAM, 4GB disk.
Click Finish to create the container.
Select the container and click Start.
Open the Console.
Run: apt update
Run: apt install -y python3 python3-venv python3-pip openssh-server git nano
Run: systemctl enable --now ssh
Run: mkdir -p /opt/lastfm-recommender
On your own computer, run: scp lastfm_recommender.py server.py requirements.txt config.example.json lastfm-dashboard.service root@<container-ip>:/opt/lastfm-recommender/
Back in the container, run: cd /opt/lastfm-recommender
Run: python3 -m venv venv
Run: source venv/bin/activate
Run: pip install -r requirements.txt
Run: cp config.example.json config.json
Run: nano config.json
Fill in your api_key, username, and timezone, then save and exit.
Run: python3 lastfm_recommender.py
Run: deactivate
Run: cp lastfm-dashboard.service /etc/systemd/system/
